# Add Worker Photo Layout

## Goal
Move the existing worker photo picker to the top of the Add Worker form and present it as a centered circular profile-photo control without changing form behavior.

## Changes
- Reorder the existing photo upload section before all worker detail fields.
- Center the circular avatar preview at the top.
- Keep the existing camera/gallery choices, validation, preview, remove action, upload, and save behavior unchanged.
- Use the existing Hindi labels and design-system controls.

## Verification
- Confirm photo selection, preview, removal, and worker submission still work.
- Check the dialog layout at desktop and mobile sizes.
- Confirm the preview build has no errors.
